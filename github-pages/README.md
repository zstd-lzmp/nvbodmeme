# 英伟达董事会调查发现生成器

一个纯前端的「假新闻梗图」生成工具：仿新闻排版，可编辑媒体名、大标题、引言、日期与左右配图，实时预览并一键导出 PNG。纯属恶搞，图一乐。

> **在线版**：<https://nvbodmeme.traesite.cn>

## 功能

- 新闻式排版：媒体名（红色）、大标题、引言、日期（默认打开当日）
- 左右两张配图，各占 50% 宽度；点击预览图区域直接触发上传
- 上传后有裁剪对话框：拖动定位、滑杆缩放，不调整则使用完整图片
- 图片完整显示（contain），比例不符时居中留白，底部留白加大
- 空图位导出时绘制虚线边框，与另一侧图片自动对齐
- 导出 PNG，支持 1x / 2x / 3x（1150×985 ~ 3450×2955）
- 纯本地处理：图片不上传到任何服务器

## 本地运行

无任何构建步骤，直接用浏览器打开 `index.html` 即可；或起一个静态服务器：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 部署到 GitHub Pages

1. 新建一个 GitHub 仓库（如 `nvbodmeme`）
2. 把本目录的全部文件（含 `.nojekyll`）推送到仓库根目录
3. 仓库 **Settings → Pages → Source** 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存
4. 约 1 分钟后访问 `https://<用户名>.github.io/<仓库名>/`

命令行方式：

```bash
git init
git add .
git commit -m "init: 英伟达董事会调查发现生成器"
git branch -M main
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

> 所有资源（头像、图标）均为 base64 内嵌，无外部请求，子路径部署无需任何改动。
